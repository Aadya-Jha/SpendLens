How it works

1
Detect
EventBridge triggers Lambda daily at 8AM UTC. It calls AWS Cost Explorer to fetch anomalies where spending exceeds expected by more than $1.
2
Deduplicate
Each anomaly is checked against DynamoDB using its unique ID. Already processed anomalies are skipped — you never get the same alert twice.
3
Explain
The anomaly is sent to Groq AI (Llama 3.3 70B). It returns a plain-English summary, most likely root cause, and 3 specific fix recommendations.
4
Alert
The explanation is emailed via SNS and stored in DynamoDB. Run the dashboard locally to view anomaly history, cost charts, and AI explanations.
